# NICU Baby Care Companion — Flutter Mobile & Web Client

A cross-platform Flutter application (Android, iOS, Web) designed for mothers of preterm infants post-NICU discharge.

## Features
- **Dynamic Age Adjuster Banner:** Automatically renders chronological age, weeks born early, and corrected gestational age according to Fenton 2013 curves.
- **Multimodal Voice & Text Input:** Speak or type questions and care logs directly.
- **1-Tap Emergency Hospital Dialer:** Pre-configured with **BirthRight by Rainbow Children's Hospital, Vijayawada** (`+91 866 666 9000`, 24/7 NICU Helpline: `+91 866 669 0000`, Ambulance: `0866-2459999`) and national 108/102 dispatch.
- **Structured Care Guidance Card:** Displays real-time clinical guidance, spoken soothing audio notes, and next feeding reminders.

## Quickstart

```bash
# 1. Install dependencies
flutter pub get

# 2. Run in Chrome (Web)
flutter run -d chrome

# 3. Or run on connected Android device / emulator
flutter run
```
